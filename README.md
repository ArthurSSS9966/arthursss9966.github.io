# Xiecheng (Arthur) Shao - Personal Website

A curated English research portfolio for BCI/ML hiring teams and scientific collaborators.

Intended URL: https://arthursss9966.github.io/

## Files

- `index.html`: profile, research, experience, selected publications, education, and contact links.
- `styles.css`: responsive light/blue editorial design with reduced-motion support.
- `favicon.svg`: initials favicon.
- `.nojekyll`: serve these static files without Jekyll processing.

No build system, JavaScript, analytics, or visitor tracking is included. Google Fonts provides optional web fonts; local serif and sans-serif fallbacks keep the page readable offline.

## Publishing

Use the GitHub repository `ArthurSSS9966/arthursss9966.github.io`. Publish these site files on `main` and configure GitHub Pages to deploy from the root of that branch. Never upload the parent job-hunt workspace, application tracking spreadsheet, source CVs, or private project data.
